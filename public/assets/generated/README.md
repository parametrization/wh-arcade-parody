# Original generated game art

Created September8,2026 with the built-in OpenAI image generation tool. Exact generation and edit prompts are in [prompts.json](prompts.json); source hashes and authorship are recorded in the root asset manifest.

- [Flappy portrait atlas](flappy-portraits-v1.png):1774×887, four columns by two rows. Top: Donald Trump, JD Vance, Mike Johnson, John Thune. Bottom: Scott Bessent, Todd Blanche, Doug Burgum, eagle courier. Original fictional editorial caricatures, not photographs. The final atlas has opaque navy backgrounds, suited to framed portrait tiles. The eagle tile is a concept and is not a transparent flight sprite.
- [National Mall backdrop](flappy-national-mall-v1.png):1536×1024 original16-bit-inspired background. Architectural/geographic composition is stylized for game readability.

The initial atlas request asked for transparency but the output included a checkerboard; a second built-in edit replaced it with navy. The discarded checkerboard version is not shipped. Images were copied unchanged into the project after generation. Runtime crops/scales do not modify the source files.
