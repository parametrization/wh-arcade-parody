# Fidelity assets

Created for this project with OpenAI's built-in image generation tool on 2026-09-08. These are generated illustrations, not photographs or evidence of real events. No third-party asset pack was copied. Rendering remains Canvas2D, not a PS3 engine.

## Prompt set and intended use

- **materials.png**: One 4×4 orthographic photographic diffuse material atlas, exact equal cells, no labels, borders, props or perspective. Row 1: weathered limestone, concrete, soil, sandstone; row 2: wood, leather, steel, mesh; row 3: canvas, wool, denim, straw; row 4: water, rock, plaster, asphalt. Neutral soft lighting, gritty realistic game materials. Delivered 1254×1254; runtime samples its cells.
- **political-heads.png**: A 4×2 atlas of isolated front-facing heads and necks, lifelike skin and hair, slight satirical exaggeration, consistent soft upper-left lighting. Exact order: Donald Trump, JD Vance, Mike Johnson, John Thune / Scott Bessent, Todd Blanche, Doug Burgum, fictional sleepy orange businessman. Requested transparent background. Delivered RGB with a baked checkerboard; consumers must contour-clip heads. These are satirical depictions, not factual allegations.
- **mall.png**: Photorealistic gritty game background of the National Mall, Capitol toward right and Washington Monument toward left, stormy sky, muted slate/olive and warm stone palette, low stone foreground, unobstructed sky/play space. No people, birds, text or interface.
- **eagle.png**: Eight consistent right-facing realistic bald eagle flight poses in a 4×2 atlas, detailed feathers, each carrying a cream envelope, isolated against dark navy #101f2c, no labels. Runtime keys the background and stabilizes the frames.
- **whitehouse.png**: Symmetric centered frontal north facade of the White House, realistic weathered limestone, overcast lighting and wet pavement, muted gritty game environment. No people or interface.

Generation produced raster source files; game renderers add lighting, animation, clipping and UI. The prompts above record the asset specifications, including known delivery limitations. No claim of true transparency is made for either character atlas.
