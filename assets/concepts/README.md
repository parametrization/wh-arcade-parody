# Original pixel-art choices

These five SVG sheets contain three concept treatments for each of 37 asset families. They are original project drawings, generated from the editable code in [build-concept-sheets.mjs](../../scripts/build-concept-sheets.mjs). Run `node scripts/build-concept-sheets.mjs` to regenerate.

- [Flappy Files — 9 asset families](flappy-files.svg)
- [Against the Wall — 8 asset families](against-the-wall.svg)
- [Rio Rescue — 6 asset families](rio-rescue.svg)
- [Supply the People — 7 asset families](supply-the-people.svg)
- [Trump Trickle-Down Tycoon — 7 asset families](trickle-down-tycoon.svg)

A uses the arcade palette, B offers a paper-satire treatment, and C uses brighter chunky cartoons. Some options vary silhouette/props; others compare palette treatments. Names identify obvious fictional satire, not historical quotations or factual allegations. The burger concepts use original packaging rather than a copied brand logo.

These are **concept options, not approved final animation atlases**. Current playable games use independent procedural drawings in their renderer files. Selecting a sheet option does not automatically change a game; runtime palette choices are available separately in the workbench. The next art pass can adopt selected silhouettes, add individualized portrait details, and export production frame atlases where useful.
