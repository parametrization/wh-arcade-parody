# Against the Wall procedural assets

The current visual assets are original Canvas drawings in ../render.ts, authored for this unofficial political satire: isometric floor and cover, actor silhouettes, detection cones, pickups, noise markers, office and political billboards. No White House sprite, photograph, font or game code is embedded. Sounds are generated through the shared synthesizer. Palette variants A/B/C are prototype presentation choices, not approved production art.

Runtime source: ../render.ts. Editable source: TypeScript drawing routines. External asset IDs: none. Attribution: wh-arcade-parody contributors, 2026. Public names identify fictional political billboards; original dialogue is not represented as a historical quotation. Detailed portrait sheets, character animation atlases and reviewed asset variants remain production work.
