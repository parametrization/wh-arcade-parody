# Original procedural art

All current game art is original Canvas pixel-style drawing in ../render.ts, authored for this parody. No White House image, font, audio or sprite code is copied. Palette A: civic sky; B: warm paper; C: evening blue. These are working palette variants, not user-approved final contact sheets. Portraits are fictional caricatures with neutral name plaques, not factual allegations. Runtime assets are self-contained; public/assets/flappy-files is reserved for future selected atlases. More elaborate individual portrait sheets and distinct body poses remain art follow-up.
